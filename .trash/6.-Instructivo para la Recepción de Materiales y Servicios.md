Instructivo para la Recepción de Materiales y Servicios

# 🎯 Objetivo

Definir el procedimiento para la correcta recepción de materiales y servicios, garantizando que lo entregado por los proveedores coincida con lo solicitado en la Orden de Compra (OC), asegurando control de inventarios y conformidad del área usuaria.

# 👤 ¿Quién participa en este proceso?

|   |   |
|---|---|
|Responsable|Función|
|Almacén|Recibe físicamente los materiales inventariables, revisa cantidades y calidad.|
|Área usuaria|Valida los servicios o bienes no inventariables y firma de conformidad.|
|Compras|Verifica que la entrega coincida con la Orden de Compra y da seguimiento con el proveedor.|
|Finanzas|Recibe documentos de entrega y válida para registro contable y pago.|

# 🔄 Flujo del proceso de recepción

1. Proveedor entrega materiales o presta el servicio según la Orden de Compra.

2. Almacén (para inventariables) o área usuaria (para no inventariables) recibe y valida la entrega.

3. Se comparan cantidades, calidad y especificaciones contra la OC.

4. Se elabora registro de recepción:

5. - En SAE para inventariables (entrada a inventario).

6. - En aplicación externa para no inventariables (acta de conformidad).

7. En caso de faltantes, daños o diferencias, se notifica a Compras para gestión con proveedor.

8. Documentos de recepción se envían a Finanzas junto con la factura.

# 📝 Campos a validar durante la recepción

|   |   |
|---|---|
|Campo|Descripción|
|Orden de Compra|Número de OC contra el cual se entrega el material o servicio.|
|Cantidad recibida|Debe coincidir con lo solicitado.|
|Calidad y especificaciones|Producto/servicio debe cumplir lo descrito en OC y ficha técnica.|
|Fecha de entrega|Debe cumplir el plazo pactado en la OC.|
|Estado del material|Revisar que no tenga daños o defectos.|
|Conformidad del área usuaria|Validación firmada de que lo recibido cumple con lo solicitado.|

# 📑 Políticas de recepción

- Ningún material o servicio se dará por recibido sin una Orden de Compra válida.

- Las entradas en SAE deben realizarse el mismo día de la recepción para inventariables.

- El área usuaria debe validar todos los servicios antes de enviar documentos a Finanzas.

- En caso de inconformidad, se debe levantar un reporte inmediato y notificar a Compras.

- No se aceptarán facturas de proveedores si no existe evidencia de recepción conforme.

# ✅ Checklist de recepción

[ ] ¿La entrega corresponde a una OC válida?

[ ] ¿Las cantidades coinciden con lo solicitado?

[ ] ¿Se revisó calidad y estado de los materiales?

[ ] ¿Se registró la entrada en SAE o acta en la aplicación externa?

[ ] ¿El área usuaria validó la conformidad?

[ ] ¿Se notificó cualquier diferencia o daño a Compras?
