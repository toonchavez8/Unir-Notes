nstructivo para la Generación de Orden de Compra (OC)

# 🎯 Objetivo

Definir el procedimiento para elaborar y registrar una Orden de Compra (OC) de manera estandarizada, asegurando la trazabilidad de cada compra y el cumplimiento de políticas internas.

# 👤 ¿Quién participa en este proceso?

|   |   |
|---|---|
|Responsable|Función|
|Compras|Genera la Orden de Compra en el sistema correspondiente.|
|Gerente/Dirección|Aprueba órdenes de compra de montos altos o estratégicos.|
|Proveedor|Confirma la aceptación de la Orden de Compra.|

# 🔄 Flujo para la generación de OC

1. Compras recibe la requisición autorizada y elabora el comparativo de cotizaciones.

2. Genera la Orden de Compra en el sistema correspondiente:

3. - SAE → Para productos inventariables.

4. - Aplicación externa → Para no inventariables.

6. Incluye en la OC: datos de proveedor, productos/servicios, cantidades, precios unitarios, subtotal, impuestos, total, y codniciones de entrega y pago.

7. Adjunta la requisición autorizada y el comparativo de proveedores.

8. Envía la OC al proveedor para confirmación.

9. Registra en el sistema la confirmación del proveedor (correo, PDF, nota digital).

# 📝 Campos obligatorios en la OC

|   |   |
|---|---|
|Campo|Descripción|
|Número de OC|Secuencia controlada con nomenclatura unificada. (Folio Sistema)|
|Datos del proveedor|Nombre, RFC, dirección, contacto, condiciones de pago.|
|Descripción de productos/servicios|Nombre claro, presentación, unidad de medida.|
|Cantidad|Número de unidades a comprar.|
|Precio unitario|Monto por unidad.|
|Subtotal e impuestos|Desglose de impuestos aplicables (ej. IVA).|
|Total|Monto total de la OC.|
|Fecha de entrega|Compromiso de entrega pactado.|
|Anexos|Requisición autorizada, comparativo de proveedores.|

# 📑 Políticas de la Orden de Compra

- Ningún pedido puede realizarse sin una Orden de Compra formal registrada.

- Todas las OC deben estar respaldadas con requisición autorizada y comparativo de proveedores.

- No se aceptarán facturas que no correspondan a una OC válida.

- La confirmación del proveedor debe quedar documentada en el sistema.

- [ ] ¿Se adjuntó la requisición autorizada?

- [ ] ¿Se adjuntó comparativo de proveedores?

- [ ] ¿El proveedor confirmó la aceptación?
