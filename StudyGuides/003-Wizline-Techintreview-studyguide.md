### Day 1: Node.js & Python Fundamentals (detailed)

**Node.js fundamentals (1–2h)**

- Refresh core concepts: **event-loop and async I/O**, modules (require/import), and basic APIs (`fs`, `http`).
    
- Example resources mentioned: ZeroToMastery Node.js interview Q&A.
    
- Practical exercise: write a simple Node.js script (HTTP server or file reader) to solidify understanding.
    
- Also brush up necessary **Python basics** for scripting (JSON parsing, file I/O, REST calls).
    

**Design tools overview (1–2h)**

- **Figma**: cloud-based collaborative design & prototyping tool (supports full design systems: styles, components).
    
    - Resource referenced: Domestika / Figma guide.
        
- **Storybook**: UI “workshop” for building and documenting components in isolation.
    
    - Suggested action: skim docs, try initializing a basic Storybook for a simple React component.
        

**Coding practice — easy (1h)**

- Do 1–2 easy algorithmic challenges in **Node.js** (arrays / strings).
    
- Use an offline editor (VS Code) to simulate the interview environment.
    
- Example exercises: filter duplicates in an array, reverse a string, simple loop logic.
    
- Timing: ~20–30 minutes per problem. Focus on correctness, clarity, and verbalizing your approach.
    

> **Study Tip:** Review Node.js interview Q&A (e.g., ZeroToMastery blog) as you practice.

---

### Day 2: Design System Tools & Mini-Project Coding (detailed)

**Algorithm practice — intermediate (2h)**

- Target medium-level problems: arrays, strings, hash tables, recursion, sorting/searching.
    
- Example problems: merge two sorted arrays, DFS on a matrix, reverse a linked list.
    
- Use LeetCode “Top Interview Questions” or similar. Time-box ~1 hour per problem. If stuck, step through patterns: DP, two-pointer, recursion.
    

**Tooling script challenge (1h)**

- Build a small Node.js script simulating a design-system task: parse a JSON file of design tokens and compare to another JSON (component styles).
    
- Use Node’s built-in modules (`fs`) and handle errors/comment code. For extra challenge, call a dummy Figma API (with `fetch` or `axios`) if available.
    

**Storybook hands-on (1h)**

- Create a Story for a simple UI component (button or card). Document the story (title, description) and run Storybook locally.
    

**Experience Q&A prep (1h)**

- Prepare concise stories for the behavioral / experience portion (first ~15 minutes).
    
- Focus on: how you contributed to a design system, how you automated workflows, challenges solved, lessons learned.
    
- Emphasize **ownership** and **innovation** (Wizeline values).
    

> **Interview Tip:** Outline your algorithm before coding and verbalize your thought process. Ask clarifying questions if anything is ambiguous.

### Day 3: AI Tools & Polishing Presentation (detailed)

**Mock Interview Session 1 (2h)**

- Simulate real structure with a partner or online tool.
    
- 15 min: experience/behavioral questions.
    
- 45–60 min: coding problem (e.g., “Given two arrays, find common elements”). Code in Node.js, explain each step, and review alternative approaches.
    

**Self-Practice — timed challenge (2h)**

- 2–3 algorithm problems, one each hour: recursion/DFS, graph traversal, hashing. Keep to 60-minute cap and afterward note improvements/edge cases.
    

**Mock Interview Session 2 (2h)**

- Focus on Node.js or design-system task (e.g., “Design a tiny system to sync colors between Figma and code”).
    
- Sketch architecture and code a function (Node.js script reading Figma JSON → update code JSON). Time-box, verbalize, ask questions.
    

**Review & Refine (2h)**

- Clean code style, comments, logging. Add small unit tests if possible. Refresh Node.js / Python specifics — e.g., Promises / async-await vs callbacks. Re-read official Wizeline interview tips.
    

**Prepare Questions & Culture Fit (1h)**

- Write questions for the interviewer about team, culture, projects. Review Wizeline values (ownership, innovation, community, inclusivity) and align your answers.
    

**Rest & Mental Prep (1h)**

- Final hour: relax; scan notes or cheat-sheets; verify microphone/camera; ensure a quiet environment. Visualize talking through a problem clearly. Sleep well.

## Node.js Interview Prep — FAQ & Snippets

### 1. What is Node.js, and why is it used?

- **Definition:** A runtime environment for executing JavaScript outside the browser.
    
- **Why it's used:** full-stack JavaScript development; non-blocking, event-driven architecture for high scalability; ideal for APIs, real-time apps, IoT, e-commerce.
    

---

### 2. What is the Node.js event loop?

- The core mechanism for handling multiple tasks on a single thread.
    
- Delegates I/O tasks to the OS; resumes when results are ready.
    
- Enables asynchronous, non-blocking processing → high performance.
    

---

### 3. What are npm and `package.json`?

- **npm:** Node Package Manager, used to install/manage dependencies.
    
- **`package.json`:** project metadata, scripts, and dependency list.
    

---

### 4. How to create a basic HTTP server in Node.js?

```javascript
const http = require('http');
const server = http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end('Hello, World!');
});
server.listen(3000, () => console.log('Server running on http://localhost:3000'));
```

- `http.createServer()` creates server.
    
- The callback handles requests/responses.
    
- `listen()` defines the port.
    

---

### 5. Differences between `require()` and `import`

- **require():** CommonJS, synchronous, works by default in Node.  
    Example: `const fs = require('fs');`
    
- **import:** ES6 modules, modern syntax, requires `"type": "module"` in `package.json`.  
    Example: `import fs from 'fs';`
    

---

### 6. What are modules in Node.js?

- **Types:** Core modules (`fs`, `http`, `path`), local modules (custom), third-party (npm).
    
- **Example:**
    

```javascript
// math.js
function add(a, b) { return a + b; }
module.exports = add;

// app.js
const add = require('./math');
console.log(add(2, 3)); // 5
```

---

### 7. What are streams in Node.js?

- Process data in chunks (memory-efficient).
    
- **Types:** Readable, Writable, Duplex, Transform.
    
- **Example:**
    

```javascript
const fs = require('fs');
const readableStream = fs.createReadStream('largeFile.txt', 'utf8');
readableStream.on('data', chunk => console.log('Chunk:', chunk));
readableStream.on('end', () => console.log('Reading complete'));
```
