# Rúbrica De Evaluación

## Criterio 1 – Correcta Automatización De Pruebas De Aceptación

|Descripción|Puntos|
|---|---|
|No se automatizan las pruebas.|0|
|Se automatizan parcialmente las pruebas pero se aportan evidencias del proceso y resultado muy limitadas.|1|
|Se automatizan parcialmente las pruebas, se aportan evidencias del proceso y alguna del resultado.|1.5|
|Se automatizan completamente las pruebas, se aportan evidencias del proceso y de los resultados, encontrando bugs.|2|
