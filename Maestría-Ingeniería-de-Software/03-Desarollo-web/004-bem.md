

# Notas de la sesión: Metodología BEM en CSS

## 1. Introducción a BEM
- Al trabajar con CSS, es recomendable usar una **metodología de nomenclatura** para las clases.
- Sin una metodología, el código CSS se vuelve **difícil de mantener**.
- **BEM** es una de las metodologías más conocidas y utilizadas.

## 2. Conceptos clave de BEM
BEM se basa en tres elementos principales:
1. **Bloque (Block)**
   - Representa una sección diferenciada de la página.
   - Ejemplos: un menú desplegable, un botón, una sección específica.
2. **Elemento (Element)**
   - Parte dentro de un bloque.
   - Ejemplos: en un menú desplegable, un botón dentro del menú, un submenú.
   - Notación: `bloque__elemento`
   - Para elementos anidados se agregan más niveles de guiones bajos según la jerarquía.
3. **Modificador (Modifier)**
   - Representa variaciones o estados de un bloque o elemento.
   - Ejemplos: botón activo, botón de añadir, botón de eliminar.
   - Notación: `bloque__elemento--modificador`

## 3. Ejemplo práctico
### HTML sin BEM
```html
<section class="subjects">
  <div class="subject active">
    <div class="title">Desarrollo Web Full Stack</div>
    <p>Descripción</p>
    <a href="#">Ir al aula</a>
  </div>
  <div class="subject">
    <div class="title">Ciberseguridad Web</div>
    <p>Descripción</p>
    <a href="#">Ir al aula</a>
  </div>
</section>
````

### HTML aplicando BEM

```html
<section class="subjects">
  <div class="subjects__subject subjects__subject--active">
    <div class="subjects__title">Desarrollo Web Full Stack</div>
    <p class="subjects__description">Descripción</p>
    <a class="subjects__link" href="#">Ir al aula</a>
  </div>
  <div class="subjects__subject">
    <div class="subjects__title">Ciberseguridad Web</div>
    <p class="subjects__description">Descripción</p>
    <a class="subjects__link" href="#">Ir al aula</a>
  </div>
</section>
```

### Observaciones

- El **bloque** es toda la sección (`subjects`).
    
- Cada **elemento** dentro del bloque sigue la notación `bloque__elemento`.
    
- Los **modificadores** indican estados o variaciones, como `--active`.
    
- No siempre es necesario mantener toda la jerarquía completa si hace que los nombres de clase sean demasiado largos.
    
- Lo importante es **mantener la relación de composición** para que el CSS sea legible y fácil de mantener.
    

## 4. Conclusión

- BEM permite organizar el CSS de manera **clara y mantenible**.
    
- Facilita la **comprensión del código** tanto para el desarrollo como para futuras modificaciones.

## MicroTest


**Pregunta 1:**  
**¿Qué es BEM?**

**Respuesta correcta:**  
**b. Una metodología que permite escribir las clases CSS haciendo referencia al uso del elemento HTML en el que se van a usar.**

**Por qué:**  
BEM no es un framework ni obliga a todas las empresas a usarlo. Es una **metodología de nomenclatura de clases CSS** que facilita la legibilidad y mantenibilidad del código. Permite identificar bloques, elementos y modificadores dentro del HTML y CSS.

---

**Pregunta 2:**  
**Los conceptos fundamentales de BEM son:**

**Respuesta correcta:**  
**d. El bloque, el elemento y el modificador.**

**Por qué:**  
BEM se compone de **tres partes**:

- **Bloque:** sección principal o componente.
    
- **Elemento:** parte del bloque.
    
- **Modificador:** variación o estado del bloque o elemento.  
    Todas son necesarias para entender y aplicar correctamente la metodología.
    

---

**Pregunta 3:**  
**¿Qué clase CSS ha sido nombrada usando BEM?**

**Respuesta correcta:**  
**c. Section__title__icon--active.**

**Por qué:**

- `Section` → bloque
    
- `title` → elemento dentro del bloque
    
- `icon` → sub-elemento del elemento
    
- `--active` → modificador que indica un estado  
    La notación **bloque__elemento--modificador** es la correcta según BEM.
