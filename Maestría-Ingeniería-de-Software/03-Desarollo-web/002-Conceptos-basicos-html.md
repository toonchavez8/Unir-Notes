
### Notas sobre Introducción a HTML

#### 1. Definición y propósito

- **HTML**: Lenguaje de marcado (no de programación) que describe la estructura de una página web.
    
- **Siglas**: _Hypertext Markup Language_.
    
- Indica al navegador cómo estructurar y mostrar el contenido.
    

---

#### 2. Herramientas para trabajar con HTML

- **Editores recomendados**: Visual Studio Code, WebStorm, Sublime Text, Atom, Notepad++.
    
- Preferencia: editores de código con soporte para sintaxis y depuración.
    

---

#### 3. Conceptos principales

##### **Elementos HTML**

- Definen partes o secciones de la página.
    
- Compuestos por etiquetas de **apertura** `<tag>` y **cierre** `</tag>`.
    
- Ejemplo: `<body> ... </body>`.
    
- Algunos elementos son vacíos y no requieren cierre, como `<br>`.
    

##### **Atributos HTML**

- Aportan información adicional a los elementos.
    
- Definidos como **pares clave-valor** dentro de la etiqueta de apertura.
    
- Ejemplo: `<img src="imagen.jpg">`.
    
- **Atributos comunes**:
    
    - `src`: ubicación de recursos.
        
    - `class`: relación con clases (para CSS).
        
    - `id`: identificador único.
        

---

#### 4. Elementos comunes

- **Tablas**
    
    - `<table>`: define la tabla.
        
    - `<tr>`: fila.
        
    - `<th>`: encabezado (en negrita).
        
    - `<td>`: celda con datos.
        
- **Formularios**
    
    - `<form>`: contenedor del formulario.
        
    - `<label>`: etiqueta descriptiva de un campo.
        
    - `<input>`: caja de entrada (puede ser `text`, `password`, `checkbox`, etc.).
        
    - `<input type="submit">`: botón para enviar datos al servidor.

## Microtest 

#### **Pregunta 1:**

**HTML es:**

**Respuesta:**  
**b. Un lenguaje de marcado utilizado para describir la estructura de una página web o parte de ella.**

**Por qué:**  
HTML (_Hypertext Markup Language_) no es un lenguaje de programación, sino un lenguaje de marcado que define la estructura del contenido en una página web.

---

#### **Pregunta 2:**

**Respuesta:**  
**d. Las respuestas B) y C) son correctas.**

**Respuesta:**  
**c. Se especifican en la etiqueta de apertura del elemento HTML.**
