
### Notas sobre Frontend

#### 1. Definición

- **Frontend**: parte de un sistema o aplicación web que interactúa directamente con el usuario.
    
- Es la capa **más cercana al cliente**, en contraste con el **backend**, que maneja la lógica y los datos pero no interactúa de manera directa.
    

---

#### 2. Tecnologías principales

- **HTML**
    
    - Lenguaje de marcado.
        
    - Define la estructura de una página web.
        
    - No es un lenguaje de programación.
        
- **CSS**
    
    - Lenguaje de diseño.
        
    - Permite agregar estilos al HTML: colores, fuentes, disposición de elementos, animaciones y diseño visual.
        
- **JavaScript**
    
    - Lenguaje de programación que aporta dinamismo a la página web.
        
    - Convierte sitios estáticos en aplicaciones interactivas.
        

---

#### 3. Otras áreas del Frontend

- **Experiencia de Usuario (UX)**:
    
    - Se enfoca en que la interacción del usuario sea fluida, agradable y eficiente.
        
- **Usabilidad**:
    
    - Busca que la aplicación sea fácil de usar, intuitiva y que la información se muestre de manera clara.
