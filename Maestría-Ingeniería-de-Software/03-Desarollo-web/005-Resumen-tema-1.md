
# Notas de Estudio: Introducción al Frontend, HTML y CSS

## 1. Frontend

### Definición
El **frontend** es la parte de una aplicación web o sistema con la que los usuarios interactúan directamente.  
Se encuentra más cercana al cliente y abarca no solo la **funcionalidad**, sino también aspectos como:

- **Experiencia de usuario (UX):** Cómo percibe y utiliza el usuario la aplicación.  
- **Usabilidad:** Qué tan fácil e intuitivo es interactuar con la aplicación.

### Relevancia
El frontend es crucial porque determina la **primera impresión** del usuario y su disposición a usar el sistema. Un buen frontend mejora la satisfacción del usuario y facilita la interacción con la aplicación.

---

## 2. Tecnologías fundamentales del Frontend

| Tecnología | Propósito | Detalles clave |
|------------|-----------|----------------|
| **HTML** | Lenguaje de marcado | Describe la estructura de la aplicación. Elementos y atributos son sus partes principales. |
| **CSS** | Lenguaje de diseño | Modifica la apariencia (look & feel) de la aplicación. Usa selectores y propiedades para definir estilos. |
| **JavaScript** | Lenguaje de programación | Aporta dinamismo e interactividad a la página web. |

---

## 3. HTML

### Elementos HTML
- Representan bloques de contenido en la página (por ejemplo: `<div>`, `<p>`, `<a>`).  

### Atributos HTML
- Proporcionan información adicional sobre los elementos.  
- Ejemplos comunes: `id`, `class`, `href`, `src`.

### Relevancia
HTML estructura la aplicación, creando el **esqueleto** sobre el cual se aplicarán estilos y funcionalidades.

---

## 4. CSS

### Definición
CSS (**Cascading Style Sheets**) es el lenguaje que controla la presentación visual de la aplicación.

### Partes clave
- **Selectores:** Determinan a qué elementos se aplican los estilos.  
- **Propiedades:** Definen qué estilo se aplica (colores, tamaños, márgenes, fuentes, etc.).  

### Ejemplo de uso
```css
/* Selector de clase */
.button-primary {
    background-color: #007bff;
    color: white;
    padding: 10px 20px;
}
````

### Relevancia

CSS permite crear aplicaciones visualmente atractivas, mejorando la **experiencia del usuario** y facilitando que interactúe con la aplicación.

---

## 5. JavaScript

### Definición

Lenguaje de programación que permite añadir **dinamismo** a la página web.

### Funciones principales

- Interactividad (respuestas a clics, formularios, animaciones).
    
- Manipulación del DOM (modificación de elementos HTML en tiempo real).
    
- Validaciones y control de eventos del usuario.
    

### Relevancia

JavaScript transforma una página estática en una experiencia **interactiva y dinámica**, aumentando la participación del usuario.

---

## 6. Resumen del tema

- El **frontend** se centra en la interacción directa con el usuario y su experiencia.
    
- **HTML** estructura la información, **CSS** define la apariencia y **JavaScript** añade interactividad.
    
- La combinación de estas tres tecnologías permite construir aplicaciones web funcionales, atractivas y fáciles de usar.
