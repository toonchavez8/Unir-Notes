# Repository Guidelines

## Project Structure & Module Organization

This repository contains study notes in Markdown, organized by topic and class sequence. Top-level files such as `00-Presentacion.md` and `11-Aspectos-sociales.md` hold the main notes, while folders like `Actividades/`, `Books/`, and `classes/` store supporting material. When adding transcript-based notes, keep one transcript in one note file and follow the existing numeric naming style, such as `01-Topic.md` 

## Transcript Note Workflow

These notes come from long transcripts and must read as complete study material, not as a summary. First, split the transcript into topics and subtopics in logical order. Then make a second pass to add context, definitions, examples, and clarifications while staying faithful to the source. Do not add filler, do not mention professors, and do not include text outside the notes.

## Content Rules

Cover every concept mentioned in the transcript. For each important idea, explain what it is, why it matters, and where it is used. If the transcript mentions a quote, include it in full and explain it below. If it mentions an algorithm, write it in LaTeX using `$$`, define each variable, explain the steps, and describe when it is used. If it includes code, include the original code and explain it line by line.

## Writing Style & Naming Conventions

Write in clear, instructional Spanish with concise Markdown headings and short paragraphs. Keep filenames ASCII, lowercase or numeric where possible, and consistent with the surrounding sequence. Use tables for comparisons, Mermaid for useful flows or relationships, and LaTeX blocks for any algorithmic content. If the transcript includes code, include it and explain it line by line. All notes must be in Spanish.

## Agent Notes

Make minimal, localized edits. Do not rename or reorganize existing notes unless the change is necessary and the affected references are updated in the same patch.
