 # Guia paso a paso - Actividad 2: Metodologias y elementos del proceso de diseno UX

## 1. Objetivo de la actividad

El objetivo de esta actividad es desarrollar una propuesta de diseno UX para el proyecto **UNIR Dev**, una herramienta de apoyo para profesionistas de TI, estudiantes de UNIR y proveedores que desean promover productos o servicios relacionados con desarrollo web y nuevas tendencias tecnologicas.

La entrega debe demostrar que se aplicaron herramientas basicas del proceso UX:

- Brief del proyecto.
- Arquitectura de informacion.
- Propuesta para facilitar la navegacion del usuario.
- Wireframes de la interfaz.

## 2. Que debes entregar

Se recomienda entregar un documento en formato PDF o Word con la siguiente estructura:

1. Portada.
2. Introduccion.
3. Brief del proyecto.
4. Publico objetivo.
5. Objetivos de la interfaz.
6. Arquitectura de informacion.
7. Estrategia de navegacion y experiencia de usuario.
8. Wireframes.
9. Justificacion de la propuesta.
10. Conclusiones.
11. Referencias, si se usaron.

Tambien puedes anexar imagenes de los wireframes hechos en Figma, Canva, Miro, Balsamiq, Draw.io, PowerPoint o cualquier herramienta similar.

## 3. Paso a paso para realizar la actividad

### Paso 1: Lee el caso de UNIR Dev

Antes de disenar, identifica los datos principales del caso:

- Nombre del proyecto: **UNIR Dev**.
- Tipo de producto: plataforma o sitio de apoyo para profesionistas de TI.
- Tematica: desarrollo web, servicios tecnologicos y tendencias digitales.
- Publicos principales:
  - Estudiantes de UNIR.
  - Proveedores que desean promover productos.
  - Profesionistas de TI interesados en actualizarse.

La idea central es proponer una interfaz clara, navegable y util para encontrar contenido, productos, servicios y recursos tecnologicos.

### Paso 2: Define el brief del proyecto

El brief debe explicar de forma breve que es el proyecto, para quien se disena y que problema busca resolver.

Incluye estos puntos:

- Nombre del proyecto.
- Descripcion general.
- Problema o necesidad.
- Objetivo del proyecto.
- Publico objetivo.
- Propuesta de valor.
- Tono visual y comunicativo.
- Funcionalidades principales.

Ejemplo de preguntas guia:

- Que es UNIR Dev?
- Que necesidad atiende?
- Quienes lo usaran?
- Que deberia poder hacer el usuario?
- Que hace diferente o atractiva esta propuesta?

### Paso 3: Identifica al publico objetivo

Describe a los usuarios principales. No basta con decir "estudiantes" o "proveedores"; explica que buscan, que problemas tienen y como la interfaz les ayudara.

Puedes dividirlos asi:

- **Estudiantes UNIR:** buscan aprender sobre desarrollo web, encontrar herramientas, consultar tendencias y descubrir oportunidades profesionales.
- **Profesionistas de TI:** buscan actualizarse, comparar tecnologias, consultar recursos y encontrar servicios especializados.
- **Proveedores:** buscan publicar productos, promover servicios y contactar posibles clientes.

Opcionalmente, agrega una persona UX sencilla:

| Persona | Perfil | Necesidad | Objetivo en UNIR Dev |
|---|---|---|---|
| Andrea | Estudiante de maestria en software | Encontrar recursos actuales sobre desarrollo web | Consultar guias, cursos y herramientas recomendadas |
| Luis | Proveedor de servicios cloud | Promocionar sus soluciones | Publicar servicios y captar contactos |

### Paso 4: Propone la arquitectura de informacion

La arquitectura de informacion explica como se organizara el contenido del sitio o aplicacion.

Para esta actividad, puedes presentarla como un mapa del sitio.

Ejemplo:

```text
UNIR Dev
|-- Inicio
|-- Tendencias tecnologicas
|   |-- Inteligencia artificial
|   |-- Desarrollo web
|   |-- Cloud computing
|   |-- Ciberseguridad
|-- Recursos
|   |-- Guias
|   |-- Tutoriales
|   |-- Cursos recomendados
|   |-- Herramientas
|-- Marketplace
|   |-- Productos
|   |-- Servicios
|   |-- Proveedores destacados
|-- Comunidad
|   |-- Eventos
|   |-- Foros
|   |-- Casos de exito
|-- Perfil
|   |-- Mis favoritos
|   |-- Historial
|   |-- Preferencias
|-- Contacto
```

La clave es que la informacion este organizada de manera logica, facil de explorar y alineada con los publicos definidos.

### Paso 5: Define como facilitaras la navegacion

Explica que elementos ayudaran al usuario a moverse por la interfaz sin confusion.

Puedes incluir:

- Menu principal visible.
- Buscador global.
- Categorias por tema.
- Filtros por tipo de contenido.
- Tarjetas con informacion breve.
- Botones de accion claros.
- Seccion de favoritos.
- Migas de pan en secciones internas.
- Recomendaciones segun intereses del usuario.

Ejemplo de flujo de navegacion:

1. El usuario entra a la pantalla de inicio.
2. Selecciona una categoria, por ejemplo "Desarrollo web".
3. Filtra por "herramientas", "guias" o "servicios".
4. Abre una tarjeta de contenido.
5. Guarda el recurso en favoritos o contacta al proveedor.

### Paso 6: Disena los wireframes

Los wireframes son bocetos de baja o media fidelidad. No necesitan tener colores finales ni imagenes definitivas, pero si deben mostrar la estructura de la interfaz.

Como minimo, se recomienda incluir 3 wireframes:

1. Pantalla de inicio.
2. Pantalla de categoria o resultados.
3. Pantalla de detalle de recurso, producto o servicio.

Tambien puedes incluir una pantalla adicional de perfil o favoritos.

Herramientas sugeridas:

- Figma.
- Canva.
- Balsamiq.
- Miro.
- Draw.io.
- PowerPoint.
- Google Slides.

### Paso 7: Justifica tus decisiones UX

Despues de presentar los wireframes, explica por que tomaste esas decisiones.

Ejemplo:

- Se usa un menu superior porque permite acceder rapido a las secciones principales.
- Se agrego un buscador global porque los usuarios de TI suelen buscar herramientas o temas concretos.
- Se usan tarjetas porque permiten comparar recursos, productos y servicios de forma visual.
- Se agregaron filtros porque el contenido tecnologico puede crecer y necesita ordenarse por categoria.
- Se incluyo una seccion de favoritos para que estudiantes y profesionistas puedan guardar contenido util.

# Actividad 2: Metodologias y elementos del proceso de diseno UX

## Portada

**Asignatura:** Experiencia e interfaz de usuario  
**Actividad:** Metodologias y elementos del proceso de diseno UX  
**Proyecto:** UNIR Dev  
**Alumno:** Nombre del alumno  
**Fecha:** Fecha de entrega

## Introduccion

El presente documento desarrolla una propuesta de diseno UX para **UNIR Dev**, una plataforma orientada a estudiantes, profesionistas de TI y proveedores de servicios tecnologicos. La propuesta busca organizar informacion relacionada con desarrollo web, tendencias tecnologicas, herramientas, productos y servicios, con una interfaz clara, navegable y centrada en las necesidades del usuario.

## Brief del proyecto

**Nombre del proyecto:** UNIR Dev.

**Descripcion:** UNIR Dev es una plataforma digital que reune recursos, tendencias, herramientas, productos y servicios relacionados con el desarrollo web y la tecnologia. Su finalidad es apoyar a estudiantes y profesionistas de TI en la busqueda de informacion actualizada, asi como ofrecer a proveedores un espacio para promocionar sus soluciones.

**Problema a resolver:** Los usuarios interesados en tecnologia suelen consultar informacion dispersa en distintos sitios. Esto dificulta comparar herramientas, encontrar recursos confiables y descubrir servicios especializados.

**Objetivo del proyecto:** Disenar una interfaz que facilite la busqueda, exploracion y consulta de recursos tecnologicos mediante una arquitectura clara, filtros utiles y una navegacion sencilla.

**Publico objetivo:**

- Estudiantes de UNIR interesados en desarrollo web y nuevas tecnologias.
- Profesionistas de TI que buscan actualizar sus conocimientos.
- Proveedores que desean promocionar productos o servicios tecnologicos.

**Propuesta de valor:** UNIR Dev centraliza informacion tecnologica relevante en una experiencia organizada, visual y facil de navegar.

**Funcionalidades principales:**

- Busqueda de recursos por tema.
- Categorias de tendencias tecnologicas.
- Marketplace de productos y servicios.
- Perfil de usuario con favoritos.
- Filtros por tipo de contenido.

## Arquitectura de informacion

La arquitectura propuesta organiza el contenido en seis secciones principales:

```text
Inicio
Tendencias
Recursos
Marketplace
Comunidad
Perfil
Contacto
```

**Inicio:** presenta recomendaciones, buscador principal y accesos rapidos.  
**Tendencias:** agrupa temas como inteligencia artificial, desarrollo web, cloud y ciberseguridad.  
**Recursos:** contiene guias, tutoriales, cursos y herramientas.  
**Marketplace:** muestra productos y servicios de proveedores.  
**Comunidad:** incluye eventos, foros y casos de exito.  
**Perfil:** permite guardar favoritos y administrar preferencias.

## Estrategia de navegacion

La navegacion se disena con un menu superior fijo, buscador global y categorias visibles desde la pantalla de inicio. Esta estructura permite que el usuario llegue rapidamente a los contenidos principales sin realizar demasiados clics.

Para mejorar la experiencia se proponen los siguientes elementos:

- Buscador central en la pagina de inicio.
- Tarjetas de contenido para presentar recursos y servicios.
- Filtros por categoria, tipo de recurso y nivel.
- Boton para guardar favoritos.
- Accesos rapidos a tendencias tecnologicas.

## Wireframes propuestos

### Wireframe 1: Pantalla de inicio

```text
+----------------------------------------------------+
| Logo UNIR Dev | Inicio | Tendencias | Recursos     |
|               | Marketplace | Comunidad | Perfil    |
+----------------------------------------------------+
| Busca herramientas, guias o servicios tecnologicos  |
| [ Campo de busqueda.......................... ][🔍] |
+----------------------------------------------------+
| Categorias destacadas                              |
| [Desarrollo Web] [IA] [Cloud] [Ciberseguridad]     |
+----------------------------------------------------+
| Recomendados para ti                               |
| [Tarjeta recurso] [Tarjeta servicio] [Tarjeta guia]|
+----------------------------------------------------+
```

**Justificacion:** La pantalla de inicio prioriza la busqueda y las categorias principales para que el usuario encuentre informacion rapidamente.

### Wireframe 2: Pantalla de resultados o categoria

```text
+----------------------------------------------------+
| Logo UNIR Dev | Menu principal | Perfil            |
+----------------------------------------------------+
| Desarrollo Web                                     |
| [Buscar dentro de la categoria................]    |
+-------------------+--------------------------------+
| Filtros           | Resultados                     |
| - Guias           | [Tarjeta: React para principiantes] |
| - Herramientas    | [Tarjeta: Hosting recomendado] |
| - Servicios       | [Tarjeta: Agencia proveedora]  |
| - Nivel           |                                |
+-------------------+--------------------------------+
```

**Justificacion:** Los filtros ayudan a ordenar la informacion cuando existen muchos recursos disponibles.

### Wireframe 3: Pantalla de detalle

```text
+----------------------------------------------------+
| Logo UNIR Dev | Menu principal | Perfil            |
+----------------------------------------------------+
| Titulo del recurso o servicio                      |
| Categoria: Desarrollo Web                          |
| Proveedor o autor                                  |
+----------------------------------------------------+
| Descripcion general                                |
| Beneficios principales                             |
| Requisitos o caracteristicas                       |
+----------------------------------------------------+
| [Guardar en favoritos] [Contactar proveedor]       |
+----------------------------------------------------+
| Recursos relacionados                              |
| [Tarjeta] [Tarjeta] [Tarjeta]                      |
+----------------------------------------------------+
```

**Justificacion:** La pantalla de detalle ofrece informacion completa y acciones claras, como guardar el recurso o contactar al proveedor.

## Justificacion general de la propuesta

La propuesta se enfoca en una experiencia simple, ordenada y orientada a la busqueda de informacion tecnologica. La arquitectura de informacion permite separar recursos educativos, tendencias y servicios comerciales, evitando que el usuario se pierda entre contenidos de distinta naturaleza.

El uso de tarjetas, filtros y buscador global facilita la exploracion. Ademas, la opcion de favoritos aporta valor para estudiantes y profesionistas que desean guardar recursos para consultarlos despues.

## Conclusiones

El diseno propuesto para UNIR Dev responde a las necesidades de sus principales publicos: estudiantes, profesionistas de TI y proveedores. La interfaz se organiza mediante una arquitectura clara, una navegacion sencilla y wireframes que muestran las pantallas esenciales del sistema. Con esta propuesta, UNIR Dev puede funcionar como una plataforma de consulta, promocion y aprendizaje sobre desarrollo web y nuevas tendencias tecnologicas.
