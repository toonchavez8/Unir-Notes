# Parte 1. Guía De Trabajo Paso a Paso

## 1. Entiende Qué Pide la Actividad

La actividad solicita desarrollar una propuesta de diseño UX para el proyecto **UNIR Dev**, una herramienta digital dirigida a personas relacionadas con tecnologías de la información.

El caso indica que UNIR Dev está pensado como una plataforma donde se encuentren productos y servicios relacionados con:

- Desarrollo web.
- Nuevas tendencias tecnológicas.
- Herramientas para profesionistas de TI.
- Recursos de apoyo para estudiantes.
- Espacios de promoción para proveedores.

Los públicos principales son:

- Estudiantes de UNIR.
- Proveedores que desean promover productos o servicios.
- Profesionistas de TI interesados en actualización tecnológica.

La entrega debe cubrir cuatro elementos principales:

1. **Brief del proyecto.**
2. **Arquitectura de información.**
3. **Propuesta para facilitar la navegación.**
4. **Wireframes de diseño UX.**

## 4. Paso 1: Define El Enfoque De Tu Propuesta

Antes de dibujar pantallas, decide qué será UNIR Dev en tu propuesta.

Para esta actividad conviene plantearlo como una **plataforma web de recursos tecnológicos, tendencias y marketplace especializado**.

Puedes usar esta definición:

> UNIR Dev es una plataforma digital orientada a estudiantes, profesionistas de TI y proveedores tecnológicos. Su objetivo es centralizar recursos, herramientas, tendencias, productos y servicios relacionados con desarrollo web y nuevas tecnologías, facilitando la búsqueda, comparación y consulta de información relevante.

Esta definición ayuda porque integra a los públicos principales:

- A los estudiantes les ofrece aprendizaje y recursos.
- A los profesionistas les ofrece actualización y herramientas.
- A los proveedores les ofrece visibilidad y contacto con posibles usuarios.

## 5. Paso 2: Construye El Brief Del Proyecto

El brief es el resumen estratégico del proyecto. No es todavía el diseño visual; es la base que explica qué se va a diseñar y por qué.

Tu brief debe responder estas preguntas:

1. ¿Cuál es el nombre del proyecto?
2. ¿Qué es el proyecto?
3. ¿Qué problema resuelve?
4. ¿A quién va dirigido?
5. ¿Qué objetivo tiene?
6. ¿Cuál es la propuesta de valor?
7. ¿Qué funcionalidades principales tendrá?
8. ¿Qué tono visual y comunicativo se recomienda?

### Ejemplo De Brief

**Nombre del proyecto:** UNIR Dev.

**Descripción:** plataforma digital de apoyo para estudiantes, profesionistas de TI y proveedores tecnológicos, enfocada en desarrollo web, herramientas digitales, tendencias tecnológicas y servicios especializados.

**Problema:** la información sobre herramientas, recursos y servicios tecnológicos suele encontrarse dispersa en diferentes sitios. Esto dificulta que los usuarios comparen opciones, encuentren recursos confiables y descubran proveedores relevantes.

**Objetivo:** diseñar una experiencia clara, organizada y fácil de navegar que permita consultar recursos tecnológicos, descubrir tendencias y conectar con productos o servicios del sector.

**Público objetivo:** estudiantes de UNIR, profesionistas de TI y proveedores tecnológicos.

**Propuesta de valor:** centralizar en una sola plataforma recursos educativos, tendencias, herramientas y servicios tecnológicos, con navegación sencilla y contenidos organizados por necesidades del usuario.

**Funcionalidades principales:**

- Buscador global.
- Categorías tecnológicas.
- Recursos educativos.
- Marketplace de productos y servicios.
- Perfil de usuario.
- Favoritos.
- Filtros por tipo de contenido.
- Contacto con proveedores.

## 9. Paso 6: Diseña la Arquitectura De Información

La arquitectura de información define cómo se organiza el contenido. Para esta actividad, puedes representarla como mapa del sitio.


### Cómo Justificar Esta Arquitectura

Puedes explicar que la arquitectura separa el contenido en bloques según la intención del usuario:

- **Inicio:** entrada rápida al contenido más importante.
- **Tendencias:** exploración temática para usuarios que buscan actualización.
- **Recursos:** materiales útiles para aprender o resolver necesidades concretas.
- **Marketplace:** productos y servicios de proveedores.
- **Comunidad:** interacción, eventos y participación.
- **Perfil:** personalización y acceso a favoritos.
- **Contacto:** comunicación institucional o comercial.

Esta organización evita mezclar contenido educativo con contenido comercial y permite que cada usuario encuentre lo que necesita con mayor claridad.

## 10. Paso 7: Define Los Flujos De Navegación

Un flujo de navegación muestra cómo se moverá el usuario para lograr una tarea.

Incluye al menos dos flujos. Esto fortalece el criterio de navegación.

### Flujo 1: Estudiante Busca Una Guía De Desarrollo Web

```text
Inicio
-> Buscador
-> Resultados
-> Filtro: Guías
-> Recurso: Guía de desarrollo web
-> Guardar en favoritos
```

**Explicación:** este flujo permite que un estudiante encuentre un recurso educativo y lo guarde para consultarlo después.

### Flujo 2: Profesionista Compara Herramientas Cloud

```text
Inicio
-> Tendencias tecnológicas
-> Cloud computing
-> Filtro: Herramientas
-> Lista de herramientas
-> Detalle de herramienta
-> Recursos relacionados
```

**Explicación:** este flujo ayuda a profesionistas a explorar soluciones tecnológicas y revisar información relacionada.

### Flujo 3: Proveedor Publica O Promociona Un Servicio

```text
Inicio
-> Marketplace
-> Proveedores
-> Perfil de proveedor
-> Publicar servicio
-> Formulario de servicio
-> Vista previa
-> Publicación
```

**Explicación:** este flujo contempla la necesidad del proveedor de mostrar sus servicios a los usuarios de la plataforma.

## 11. Paso 8: Define Elementos Para Captar El Interés De Navegación

La actividad menciona que se busca captar el interés y facilitar la navegación. Para cubrir este punto, debes explicar qué recursos UX usarás.

Elementos recomendados:

1. **Buscador global:** permite buscar herramientas, guías, servicios o tendencias desde cualquier sección.
2. **Categorías visible:** ayudan a explorar temas sin necesidad de escribir una búsqueda.
3. **Tarjetas de contenido:** muestran título, descripción breve, categoría y acción principal.
4. **Filtros laterales:** permiten refinar resultados por tipo, nivel, tema o proveedor.
5. **Favoritos:** permiten guardar recursos útiles.
6. **Recomendaciones:** sugieren contenido relacionado.
7. **Botones de acción claros:** por ejemplo, "Ver recurso", "Guardar", "Contactar proveedor".
8. **Jerarquía visual:** títulos, subtítulos y espacios bien organizados para facilitar lectura.
9. **Migas de pan:** muestran en qué sección está el usuario.
10. **Diseño consistente:** mismo patrón de tarjetas, botones y navegación en todas las pantallas.

Puedes justificarlo así:

> Estos elementos reducen el esfuerzo del usuario, permiten encontrar información en menos pasos y hacen que la navegación sea más clara. Además, el uso de filtros, favoritos y recomendaciones mantiene el interés porque permite personalizar la experiencia.

## 17. Paso 10: Convierte Los Wireframes Textuales En Imágenes

Para que la entrega sea más fuerte, no dejes los wireframes solo en texto. Conviene recrearlos como imágenes.

### Opción Rápida En Canva O PowerPoint

1. Crea una diapositiva horizontal.
2. Agrega un rectángulo superior para el menú.
3. Agrega cajas para buscador, categorías y tarjetas.
4. Usa escala de grises o colores suaves.
5. Usa textos breves.
6. Exporta cada pantalla como imagen PNG.
7. Inserta las imágenes en el documento.

### Opción Recomendada En Figma

1. Crea un archivo nuevo.
2. Agrega un frame de escritorio, por ejemplo 1440 x 1024.
3. Diseña el menú superior.
4. Crea components simples para tarjetas y botones.
5. Duplica el frame para cada pantalla.
6. Ajusta cada pantalla según el flujo.
7. Exporta los frames como PNG.
8. Inserta las capturas en tu documento.

### Estilo Visual Recomendado

Aunque un wireframe puede set en blanco y negro, puedes usar una presentación sobria:

- Fondo blanco o gris claro.
- Títulos en color oscuro.
- Botones en azul institucional o azul tecnológico.
- Tarjetas con bordes suaves.
- Texto breve y ordenado.

Evita saturar el wireframe con demasiado texto. La finalidad es mostrar estructura, no diseño final.

## 1. Introducción

El presente documento desarrolla una propuesta de diseño UX para **UNIR Dev**, una plataforma orientada a estudiantes, profesionistas de tecnologías de la información y proveedores de productos o servicios tecnológicos.

La propuesta tiene como finalidad organizar los contenidos de la plataforma de manera clara, facilitar la navegación del usuario y presentar wireframes que representen la estructura inicial de la interfaz. Para ello, se plantea un brief del proyecto, una arquitectura de información, flujos de navegación y una series de pantallas base que muestran cómo podría funcionar la experiencia digital.

El enfoque de diseño se centra en que los usuarios puedan encontrar recursos, herramientas, tendencias y servicios tecnológicos de forma rápida, ordenada y útil.

## 2. Contexto Del Proyecto

UNIR Dev se plantea como una herramienta de apoyo para personas relacionadas con el sector tecnológico. Su propósito es reunir información, productos y servicios vinculados con el desarrollo web y las nuevas tendencias digitales.

Actualmente, los usuarios interesados en tecnología suelen consultar diferentes sitios para encontrar tutoriales, herramientas, proveedores, cursos, guías o tendencias. Esta dispersión puede generar pérdida de tiempo, dificultad para comparar opciones y problemas para identificar recursos confiables.

Por esta razón, UNIR Dev se propone como una plataforma centralizada que permita consultar contenido tecnológico, descubrir tendencias y conectar con proveedores especializados.

## 3. Brief Del Proyecto

### 3.1 Nombre Del Proyecto

**UNIR Dev**

### 3.2 Descripción General

UNIR Dev es una plataforma digital enfocada en desarrollo web, recursos tecnológicos, tendencias digitales y servicios especializados para el sector TI. La plataforma busca apoyar a estudiantes, profesionistas y proveedores mediante una experiencia organizada, clara y fácil de navegar.

### 3.3 Problema O Necesidad

La información relacionada con desarrollo web, herramientas tecnológicas, tendencias y servicios especializados se encuentra distribuida en múltiples sitios. Esto dificulta que los usuarios encuentren información confiable, comparen opciones y accedan rápidamente a recursos útiles.

Además, los proveedores tecnológicos necesitan espacios donde puedan presentar sus productos y servicios ante una audiencia interesada en el sector TI.

### 3.4 Objetivo Del Proyecto

Diseñar una propuesta de interfaz UX para UNIR Dev que facilite la búsqueda, exploración y consulta de recursos tecnológicos, así como la promoción de productos y servicios especializados.

### 3.5 Público Objetivo

La plataforma se dirige a tres públicos principales:

- **Estudiantes de UNIR:** usuarios que buscan recursos de aprendizaje, guías, tutoriales y herramientas para fortalecer sus conocimientos.
- **Profesionistas de TI:** usuarios que desean actualizarse, comparar soluciones y consultar tendencias aplicables a su trabajo.
- **Proveedores tecnológicos:** empresas o profesionales que desean promocionar productos, servicios, capacitaciones o soluciones digitales.

### 3.6 Propuesta De Valor

UNIR Dev ofrece una experiencia centralizada para descubrir, consultar y guardar recursos tecnológicos. Su valor principal es reunir contenido educativo, tendencias y servicios especializados en un mismo entorno, con navegación sencilla y organización clara.

### 3.7 Funcionalidades Principales

Las funcionalidades principales propuestas son:

- Buscador global de recursos, herramientas, proveedores y tendencias.
- Categorías tecnológicas destacadas.
- Sección de recursos educativos.
- Marketplace de productos y servicios.
- Filtros por tema, nivel, tipo de contenido y tecnología.
- Perfil de usuario con favoritos e historial.
- Sección de recomendaciones.
- Botones de contacto para proveedores.

### 3.8 Tono Visual Y Comunicativo

El tono visual debe set professional, tecnológico y claro. Se recomienda utilizar una interfaz limpia, con jerarquía visual, colores sobrios y components consistentes. El lenguaje debe set directo, comprensible y orientado a la acción.

## 9. Estrategia Para Facilitar la Navegación

Para mantener el interés del usuario y facilitar la navegación, se proponen los siguientes elementos de interfaz:

- **Menú superior fijo:** permite acceder a las secciones principales desde cualquier pantalla.
- **Buscador global:** facilita la búsqueda directa de recursos, servicios o tendencias.
- **Categorías destacadas:** ayudan al usuario a explorar sin necesidad de conocer términos específicos.
- **Filtros laterales:** permiten ordenar resultados por tipo, nivel, tecnología o proveedor.
- **Tarjetas de contenido:** muestran información resumida y acciones claras.
- **Favoritos:** permiten guardar recursos importantes.
- **Recomendaciones:** sugieren contenidos relacionados con los intereses del usuario.
- **Migas de pan:** ayudan a entender la ubicación dentro del sitio.
- **Botones de acción claros:** guían al usuario hacia acciones como ver, guardar o contactar.

Esta estrategia busca que la experiencia sea comprensible, eficiente y útil para los distintos tipos de usuarios.

## 11. Justificación General De la Propuesta UX
