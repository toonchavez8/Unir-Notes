# Introducción

En esta guía, se proporcionan instrucciones para aprender a usar el AWS Academy Learner Lab.

En esta guía, se explica cómo configurar e iniciar sesión en su cuenta de AWS Academy, cómo acceder a un AWS Academy Learner Lab y cómo usarlo.

# Configuración E Inicio De Sesión En la Cuenta De AWS Academy

## 1

Para configurar su cuenta de AWS Academy, abra la invitación por correo electrónico de AWS Academy (`notifications@instructure.com`) y elija **Get Started (Comenzar)**.

![[{0F89506F-5D3B-4F5B-8E89-5794C1F8EA01}.png]]

> **Nota:**  
> Si no encuentra el correo electrónico, revise la carpeta de correo no deseado, spam o promociones.

---

## 2

Vaya a:

`https://www.awsacademy.com/LMS_Login`

---

## 3

Elija **Student Login (Inicio de sesión de estudiantes)** e inicie sesión con su dirección de correo electrónico y contraseña.

![[{36EBDE49-1361-4096-AB94-8FFF556CAAF2}.png]]

> **Nota:**  
> Utilice la dirección de correo electrónico en la que recibió la invitación por correo electrónico de AWS Academy.

# Uso De Un AWS Academy Learner Lab

## 1

Para iniciar el laboratorio, haga clic en:

![[{91B20463-5A13-4A71-AC57-033B6A4C3118}.png]]

**Start Lab (Comenzar laboratorio)**

---

## 2

Cuando el ícono del círculo en el lado derecho del enlace de AWS en la esquina superior izquierda aparece en verde, el entorno del laboratorio está listo para usarse.

Para iniciar la Consola de administración de AWS en una pestaña nueva, elija el enlace de **AWS**.

Se inicia sesión en la consola con una cuenta de AWS temporal que podrá usar durante el tiempo que el temporizador de la sesión del laboratorio esté activo.

El sistema guardará el trabajo cuando determine la sesión o caduque el temporizador de esta.

![[{0E892C66-EA71-4D31-9DD0-D75AD6A28CBE}.png]]

Como alternativa, puede usar el panel de terminal en el panel de instrucciones del laboratorio para usar la **Interfaz de línea de commandos de AWS (AWS CLI)** para interactuar con la cuenta temporal de AWS.

![[{C749A8E7-D846-4600-876A-A6850F965E1D}.png]]

---

## 3

Para ver las instrucciones del laboratorio, vuelva al LMS y seleccione:

**Readme (Léame)**

Las instrucciones explican:

- Cómo acceder y utilizar la cuenta de AWS
- Los servicios de AWS disponibles
- Restricciones impuestas a algunos servicios de AWS

---

## 4

Para supervisar los gastos, revise la sección en la parte superior de las instrucciones del laboratorio.

![[{DA94BB11-1482-4A8C-B37E-8C3981F6CC0F}.png]]

> **Nota:**  
> El servicio de **AWS Budgets** proporciona esta información y puede tener un retraso de hasta **8 horas**. Se trata de una vista aproximada del gasto.

> **Nota:**  
> Si gasta el presupuesto completo, perderá todo su trabajo y el sistema desactivará su cuenta temporal de AWS.

Su presupuesto de **50 USD** para la plataforma de AWS es suficiente para la mayoría de los proyectos académicos, siempre y cuando se mantenga dentro de las pautas del presupuesto.

![[{70BCBF7B-ED20-4C88-A61E-9FC425F2D0C3}.png]]

---

## 5

Para supervisar el tiempo restante de la sesión, revise la sección en la parte superior de las instrucciones del laboratorio.

![[{E901F4E7-001E-4880-9482-B9D5FEFB7959}.png]]

> **Nota:**  
> Si está trabajando de manera activa y necesita más tiempo, seleccione nuevamente:

**Start Lab (Comenzar laboratorio)**

para reiniciar el temporizador de la sesión.

---

## 6

Para eliminar todos los recursos que configuró en el laboratorio y comenzar con una nueva cuenta de AWS, elija:

**Reset (Restablecer)**

> **Importante:**  
> Todo el trabajo se perderá y no se podrá recuperar.

Esta opción no restablecerá el presupuesto.

Cualquier gasto en el que haya incurrido se seguirá rastreando.

![[{7E7217B0-4B1A-402E-929D-358D17630C03}.png]]

---

## 7

Cuando determine la sesión, elija:

**End Lab (Finalizar laboratorio)**

Cualquier instancia en ejecución de **Amazon Elastic Compute Cloud (Amazon EC2)** se detendrá.

Si vuelve y reinicia el laboratorio:

- Las instancias EC2 detenidas se reiniciarán
- Los demás recursos configurados seguirán disponibles

> **Importante:**  
> Si creó e inició otros recursos de AWS, como:

- Una puerta de enlace NAT
- Una base de datos de Amazon Relational Database Service (Amazon RDS)

estos recursos continuarán ejecutándose en segundo plano y generarán cargos incluso fuera del tiempo de sesión del laboratorio.

# Cómo Usar De Manera Eficaz Los AWS Academy Learner Labs

El curso **AWS Academy Learner Lab (Español LATAM)** brinda acceso al módulo:

**AWS Academy Learner Lab: cumplimiento y seguridad**

Este módulo está diseñado para ayudar a educadores y estudiantes a adquirir conocimientos sobre las responsabilidades de cumplimiento y seguridad que deben cumplirse cuando se usan servicios de AWS a través del AWS Academy Learner Lab.

Los educadores y estudiantes tienen acceso a:

- Materiales de lecciones
- Evaluación de conocimientos en línea opcional

---

# Objetivos Del Módulo

Al finalizar este curso, el estudiante podrá:

- Identificar las funciones y pautas de cumplimiento del AWS Academy Learner Lab.
- Identificar el modelo de responsabilidad compartida de AWS.
- Identificar un conjunto de prácticas recomendadas para la seguridad de AWS.
- Reconocer prácticas recomendadas de cumplimiento y seguridad del AWS Academy Learner Lab.
- Identificar dónde encontrar recursos de seguridad de AWS.

---

# Duración

Aproximadamente:

**20 minutos**

El módulo está diseñado para revisarlo antes de usar el AWS Academy Learner Lab.

Es altamente recomendable que los educadores exijan a los estudiantes revisar el contenido y completar la evaluación antes de comenzar el laboratorio.

---

# Audiencia Objetivo

Este módulo sobre cumplimiento está dirigido a estudiantes que asisten a instituciones miembro de AWS Academy y desean usar un AWS Academy Learner Lab para realizar proyectos durante un periodo designado por el educador.

AWS Academy recomienda a educadores y estudiantes revisar este módulo para aprender a usar eficazmente el AWS Academy Learner Lab.

# ¿Necesita Ayuda?

AWS Academy Learner Lab proporciona un entorno de pruebas prolongado para explorar servicios de AWS.

Su instructor puede:

- Ofrecer una asignación específica
- Permitir trabajar en un proyecto propio

Si tiene preguntas sobre el uso de servicios de AWS:

1. Elija **Help (Ayuda)** en el LMS
2. Seleccione:

**Ask Your Educator A Question**  
(Hágale una pregunta a su educador)

Si el entorno del laboratorio no funciona correctamente:

1. Elija **Help (Ayuda)** en el LMS
2. Seleccione:

**Student Support Contact Form**  
(Formulario de contacto de soporte para estudiantes)
