# Introducción a AWS: Consola AWS, Servicios EC2 Y RDS

## Objetivos

El objetivo principal de esta actividad es desarrollar los conocimientos obtenidos a través de los temas dedicados a nube pública.

## Pautas De Elaboración

### Tarea 1. Uso De AWS Academy Y Consola De AWS

En esta tarea el alumno debe utilizar la consola de AWS en la plataforma AWS Academy, a la cual se le dará acceso con su correo de la universidad. Deberá investigar la plataforma, así como la consola inicial de AWS.

### Tarea 2. Instalación De Una Página Web En Una Instancia EC2 Linux

El servidor web puede set Apache o Nginx. La página puede set cualquier página web estática.

Recurso sugerido:

[Netflix.zip](https://s3.eu-west-1.amazonaws.com/www.profesantos.cloud/Netflix.zip)

### Tarea 3. Instalación De Una Página Web En Una Instancia EC2 Windows

El servidor web puede set Apache o Internet Information Server (IIS). La página puede set cualquier página web estática.

Recurso sugerido:

[breakout.zip](https://sanvalero-static-webs.s3.eu-west-1.amazonaws.com/breakout.zip)

### Tarea 4. Instalación De Una Base De Datos MySQL En AWS RDS

Se instalará una base de datos MySQL en capa gratuita en el servicio AWS RDS. En MySQL debe crearse una base de datos con cualquier nombre. Se deberá conectar con la base de datos mediante un gestor como HeidiSQL o cualquier otro que el alumno conozca.

## Extensión Y Formato

- La entrega consistirá en un informe en un archivo PDF.
- La extensión máxima será de quince páginas.
- El documento debe usar fuente Calibri, tamaño 11 e interlineado de 1,5 líneas.
