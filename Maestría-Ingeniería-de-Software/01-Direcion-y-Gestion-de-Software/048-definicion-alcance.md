# Notas De la Clase: Definición Del Objetivo, Alcance, WBS Y RAM

## Objetivo Del Proyecto

- Definir **qué se quiere lograr** con el proyecto.
    
- Ejemplo del caso práctico:
    
    - Proyecto de un almacén de cadena de frío con dos tipos de clientes:
        
        - Grandes cadenas.
            
        - Pequeños comercios (restaurantes o tiendas).
            
    - Objetivo: dotar al cliente de una **solución logística** que permita:
        
        - Entrada de hasta **1.200 cajas/hora**.
            
        - Salida de hasta **1.000 cajas y 80 palettes/hora**.
            
        - Mantener la **cadena de frío** con **90% de disponibilidad**.
            
        - Puesta en servicio en **febrero 2025** y régimen permanente antes de **junio 2025**.
            
    - Herramienta: **aplicación software para la gestión inteligente de almacenes**.

---

## Alcance Del Proyecto

- Define el **trabajo necesario** para entregar el producto o servicio al cliente.
    
- Responde a:
    
    - ¿Qué entregables necesita el cliente?
        
    - ¿Qué trabajo hay que realizar para producirlos y entregarlos?
        
- Alcance del ejemplo:
    
    - Diseño, construcción, instalación y puesta en servicio de sistemas de **entrada y identificación de cajas**.
        
    - Formación de **palettes** y almacenaje:
        
        - Cajas y palettes a menos de 24°C.
            
        - Salida y expedición de cajas y palettes.
            
    - Control mediante **software de gestión de almacén** desarrollado a medida.
        
    - Monitoreo con **sistema de visualización personalizado**.
        
- **Nota:** Alcance del proyecto ≠ Alcance del producto; el primero incluye al segundo y se ve afectado por él.

---

## Estructura De Desglose Del Trabajo (EDT / WBS)

- **Definición:** Descomposición jerárquica orientada al producto o entregable, relativa al trabajo que ejecutará el equipo del proyecto.
    
- Propósito:
    
    - Organizar el trabajo.
        
    - Agregar objetivos del proyecto.
        
    - Crear los productos entregables requeridos.
        
- Ejemplo de descomposición:
    
    - Operaciones de ingeniería.
        
    - Operaciones de montaje.
        
    - Puesta en marcha.
        
    - Gestión de propiedad del proyecto.
        
    - Mantenimiento del almacén.

---

## Organigrama Del Proyecto (OBS)

- **Definición:** Diagrama jerárquico que representa los recursos humanos y sus capacidades disponibles para lograr el objetivo del proyecto.
    
- Propósito:
    
    - Entender la comunicación.
        
    - Descomponer funciones y responsabilidades.
        
- Preguntas clave:
    
    - ¿Qué departamentos deben intervenir?
        
    - ¿Con qué personas cuento para formar el equipo?
        
- Ejemplo: un organigrama que muestra departamentos y roles responsables de cada área del proyecto.

---

## Matriz De Asignación De Responsabilidades (RAM)

- **Definición:** Herramienta para **relacionar actividades con recursos** (individuos o equipos).
    
- Propósito:
    
    - Asegurar que cada componente del alcance tenga un responsible asignado.
        
- Consideraciones:
    
    - RAM puede indicar **responsabilidad a alto nivel** (departamentos).
        
    - Luego cada departamento asigna **personas concretas** con recursos necesarios.

---

## Resumen De Pasos

1. Definir **objetivo** del proyecto.
    
2. Definir **alcance** del proyecto.
    
3. Crear la **EDT / WBS** para organizar el trabajo.
    
4. Diseñar el **OBS** para identificar recursos y comunicación.
    
5. Crear la **RAM** para asignar responsabilidades.
